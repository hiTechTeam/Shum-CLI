# Проверка CLI 0.1.7

10 октября 2026, macOS на Apple Silicon.

## Изменения

Регистрация показывает сборку ключа и щита, плавную шкалу и четыре галочки.
После завершения появляются имя и аватар из открытого ключа подписи.
PNG для Warp увеличен с 36×36 до 576×576 без сглаживания исходных пикселей.
Имена профилей могут совпадать; выбор и удаление используют полный ID.
`shum daemon --uninstall --purge` удаляет профили и ключи после подтверждения DELETE.

Ядро: `93df2317c4fbbca8f405f643f7609aa7c1da91f7`. Wire-форматы не изменены.

## Проверки перед упаковкой

- 21 тест регистрации, аватаров, вывода и TUI прошёл; Clippy без предупреждений.
- PTY для Apple Terminal и Warp: анимация перед именем, затем аватар; цвета,
  PNG и восстановление терминала после Ctrl+Q проверены.
- Отмена на второй и пятой секунде анимации: exit 0, профилей и временного
  зашифрованного хранилища не остаётся.
- PNG декодирован из фактического вывода: 576×576, каждый исходный пиксель,
  прозрачность и фрагменты передачи проверены.
- `tests/tui.rs` сохранён без изменений, SHA-256:
  `6e90abd725b58572c4807abca1ea3ec919feb3641cd346906fa14f43e3a8538e`.

## Публикация и установка на Mac владельца

Выпуск опубликован в [CLI](https://github.com/hiTechTeam/Shum-CLI/releases/tag/v0.1.7)
и [tap](https://github.com/hiTechTeam/homebrew-shum/releases/tag/v0.1.7).
Оба latest указывают на v0.1.7, в каждом пять одинаковых артефактов.
Формула tap: `30f7ef918e7b7f43935a947db357b15bdb5ddc5f`.

`brew upgrade hitechteam/shum/shum` установил 0.1.7. `brew test shum` прошёл.
Команда `/opt/homebrew/bin/shum --version` возвращает `shum 0.1.7`;
`daemon --help` содержит `--purge` и `--confirm`. SHA-256 установленного
бинарника совпадает с проверенным архивом.

Штатный refresh существующего профиля дошёл до запуска процесса 0.1.7,
но ожидание готовности истекло через 60 секунд. Стек нового процесса показывает
ожидание Security.framework при загрузке ключа профиля из Keychain.
Владелец разрешил доступ в системном окне. После этого `shum --json status`
успешно ответил: служба 0.1.7, SHA-256
`223c26441e53b6d4adc8ed872d6f88e09537b258ae89303af6e0239b45242e1b`.
Bluetooth сообщает `scanning` и `advertising`; поле `link` содержит
`Shum GATT characteristic missing`. Владелец затем подтвердил, что обмен
работает. Маршрут доставки через Bluetooth отдельно не проверялся.
Поле `relays` формируется из подключений `pool.connected()`.
Профили владельца и переписка не удалялись.

## Ограничения проверки

macOS 15+, Apple Silicon и Intel. На настоящем Intel Mac проверки не было.
Rosetta не заменяет настоящий Intel Mac. Самоподписанная подпись не является
Developer ID; нотарификации нет. Проверка Gatekeeper на чистой учётной записи
и отсутствие повторного запроса Bluetooth между 0.1.6 и 0.1.7 не подтверждены.
Результаты предыдущего выпуска: [0.1.6](release-verification.md).
